# 🧠 Multi-Dimensional Clustering Guide (Securities) ## 🎯 Goal Enable clustering across **multiple dimensions**: - Geography (LATAM, JP, US) - Exchange (XHG, TSE, NYSE…) - Name semantics (Tech, Bank, Energy…) --- ## 🧩 Mental Model Tech ▲ 
LATAM ● ● JP ● US
- Horizontal → Geography - Vertical → Name / Sector - Points → Securities - Clusters → Balance of forces --- ## 📦 Input Schema ``json { "isin": "string", "xchg": "string", "currency": "string", "country": "string", "name": "string", "pricedate": "yyyymmdd" } 
⚙️ Step 1 — Feature Construction
1.1 Name Embedding
name_vector = embed(name) 
Captures:
company similarity
sector / industry
brand semantics
1.2 Structured Encoding
xchg_vec = one_hot(xchg) country_vec = one_hot(country) currency_vec = one_hot(currency) 
1.3 Combine Features
final_vector = concat( name_vector, xchg_vec, country_vec, currency_vec ) 
⚖️ Step 2 — Weight Control (Critical)
Control clustering behavior:
final_vector = concat( 0.7 * name_vector, 0.3 * geo_vector ) 
Where:
geo_vector = concat(xchg_vec, country_vec, currency_vec) 
🔁 Step 3 — Normalize
final_vector = normalize(final_vector) 
Prevents one feature group from dominating.
🎯 Step 4 — Clustering
kmeans = KMeans(n_clusters=K) labels = kmeans.fit_predict(final_vector) 
🔍 Step 5 — Evaluate Clusters
Check if clusters align with:
DimensionExpected SignalGeographyLATAM / JP / USNameTech / Bank / EnergyExchangeSecondary grouping
